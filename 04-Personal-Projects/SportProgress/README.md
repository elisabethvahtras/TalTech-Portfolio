# SportProgress

A personal sports performance tracking application built with Python and Streamlit.

## About the project
SportProgress is an application for recording and analysing swimming results, tracking progress and setting personal goals.

## Technologies
- Python
- Streamlit and Pandas (used in the project, still learning)

## Features
- Recording swimming results
- Analysing performance
- Tracking personal goals
- Athlete profile and medals

## Status
Work in progress. More features are planned.

## How to run the application
1. Install the required libraries:
   pip install -r requirements.txt

3. Start the application:
   streamlit run app.py

The application opens in a web browser.
