# Roblox Game Project

My first game development project created using Roblox Studio.

## About the Project

I created this game as a personal learning project to explore game development, user interface design and game mechanics.

## Technologies
- Roblox Studio
- Lua scripting

## Development Process

I worked on this project through experimenting, problem-solving and learning from YouTube tutorials.

When I encountered more difficult challenges, I used ChatGPT to help me understand problems, find solutions and improve the game.

Throughout the development process, I continued learning, testing and making improvements.
